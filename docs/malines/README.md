# أرشيف مالينز — سيناريوهات النسخ السابقة

أرشيف السيناريوهات الحربية من النسخ السابقة للعبة، محفوظ هنا كمرجع للواقعية وبنية السرد.

- **المصدر**: `https://malines.ivanova.sbs/archive` — جُلب في 29 سبتمبر 2026 (24 وثيقة، ~414 ألف حرف).
- كل سيناريو محفوظ بنصه الأصلي كاملًا مع ترويسة (العنوان، التصنيف، تاريخ النشر، المصدر).

## أهم ما كشفه التحليل

- **الواقعية الصارمة** هي القاعدة الذهبية: جداول موازين قوى قبل كل معركة، خسائر مفصلة لكل وحدة (حتى الخيول)، والمدنيون بندٌ منفصل يُحسب حتى لو كان صفرًا.
- **اللوجستيات هدف مستقل**: قطع الإمداد، الأرض المحروقة، والدفاع الجوي كمورد قابل للنفاد.
- **المهزوم يُدمج لا يُباد** هو النموذج الغالب (حكم تابع / دولة مرتبطة).
- الملف الأضخم («معمعة الدماء والفولاذ») يحتوي ~94% تقارير عملياتية مكررة متطابقة الصيغة — المحتوى السردي الحقيقي ~14.5 ألف حرف فقط.
- فصول الملحمة 1–58 و60–94 وغيرها **مفقودة من الأرشيف** — ما لدينا مقتطفات من عمل أطول.

التفاصيل الكاملة في `ANALYSIS.md`.
